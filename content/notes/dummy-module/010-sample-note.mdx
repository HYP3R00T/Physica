## Moving at a steady speed

An object moving at a steady speed covers the same distance each second. Give it twice as much time, and it travels twice as far.

## Distance, speed, and time

To find the distance travelled at a constant speed, multiply the speed by the time:

$$
d = vt
$$

At $2\,\mathrm{m/s}$, an object travels $6\,\mathrm{m}$ in $3\,\mathrm{s}$.

## Calculate it in Python

```python
speed = 2  # metres per second
time = 3   # seconds
distance = speed * time
print(distance)
```
